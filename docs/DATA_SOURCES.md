# 데이터 출처와 이용 조건

최신 확장분은 `EXPANSION.md`를 참조한다. 현재 술 항목 330건, 문서 연결 330건, 사주 개념 원문 15개다. 한국어 Wikipedia 자료도 포함하며 동일하게 CC BY-SA 4.0의 출처·리비전·변경 내용을 기록한다. 사주 개념은 별도 `saju_reference` 컬렉션에 색인하고, 전통 용어의 설명 근거로만 사용한다.

## 확보 현황

- 최초 수집: 2026-10-21 14:55 KST.
- Wikidata 항목 160건, 중복 ID 0건.
- 모든 항목에 영어 Wikipedia 설명 문서 연결. 실제 수치는 `data/collection_report.json` 참조.
- 문서 연결 레코드 160건의 고유 원문은 158개다. Adios Motherfucker는 Long Island iced tea 문서로, Bloody Margaret는 Bloody Mary 문서로 연결된다. 원문의 변형 설명이 해당 항목의 근거가 되는지 검색 시 확인해야 하며, 같은 원문이라도 항목 ID를 분리하여 저장한다.
- 수집 스크립트는 실시간 원문을 받아 저장하며 가짜 항목·생성 레시피를 만들지 않는다.
- 우선 칵테일 도메인으로 한정한다. 소주·맥주·와인 브랜드 DB는 아직 포함하지 않는다.
- Wikipedia 연결 언어 수(sitelinks)가 많은 순서로 수집했다. 이는 대중성의 대리 지표이며 모든 항목이 국내에서 대중적이라는 검증은 아니다. 대중적인 항목을 첫 화면에 우선 배치하고, 160건 전체를 도감으로 제공한다.

## Wikidata

- API: https://query.wikidata.org/sparql
- 선정 조건: cocktail(Q134768)의 인스턴스 또는 하위 분류이며 영어 Wikipedia 문서가 연결된 항목.
- 속성: ID, 이름, 영문 문서명, 설명, sitelinks, 항목 URL.
- 라이선스: CC0 1.0. https://www.wikidata.org/wiki/Wikidata:Licensing
- 수집 결과: `data/alcohols.json`. 각 항목의 원문 URL과 수집 시각을 기록.
- 도수와 당도는 검증 없이 생성하지 않으며 현재 null이다. 검색·추천 시 확인되지 않은 수치 조건은 만족한다고 단정하지 않는다.

## English Wikipedia

- API: https://en.wikipedia.org/w/api.php
- 항목 자체의 문서를 우선 수집. 초기 소개문을 확보한 뒤 전체 본문으로 보강한다.
- 라이선스: CC BY-SA 4.0. https://creativecommons.org/licenses/by-sa/4.0/
- 이용 조건: https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use
- 수집 결과: `data/documents.json`.
- 문서마다 제목, 원문 URL, 리비전 ID·시간·고정 링크, 언어, 저작자 표시, 라이선스, 텍스트 추출 방식 기록.
- 재배포·변형 시 저작자 표시, 원문·라이선스 링크, 변경 내용 표시 및 동일조건변경허락 의무를 준수한다. 데이터 원문은 해당 라이선스를 유지한다.
- 이미지 라이선스가 별도이므로 이미지 파일은 수집하지 않는다.
- API 요청 시작은 전체 작업 기준 최소 1초 간격으로 제한한다. 전체 본문 보강은 최대 4개 요청을 대기 상태로 처리하며, 429 및 서버 오류 재시도·Retry-After, 응답 캐시를 적용한다.
- `.env`의 `WIKIMEDIA_USER_AGENT`를 실제 프로젝트 연락 URL/이메일을 포함하도록 변경해야 한다. 기본 식별자는 로컬 교육용 프로젝트임만 표시하며, 연락처 제공 요건 검증은 미완료다.

## 사주 계산 라이브러리

국내 제품 보강: 청하·참이슬·처음처럼·한라산·백세주·복분자주·클라우드·하이트는 한국어 위키백과의 고정 리비전에서 본문 문단을 추출합니다. 제조사 항목과 제품 항목을 구분합니다.
진로 소주는 [하이트진로 공식 보도자료](https://www.newswire.co.kr/newsRead.php?no=959487)의 사실 관계를 프로젝트에서 짧게 요약했습니다. 보도자료 원문의 권리는 원저작자에게 있으며 원문을 재배포하지 않습니다. 프로젝트가 작성한 사실 요약·메타데이터만 CC0로 제공합니다. 당시 발표를 현재 도수·성분표로 간주하지 않습니다.

- lunar-python 1.4.8: https://github.com/6tail/lunar-python (MIT).
- 양력 입력, 절기 기반 간지, sect=2. 태어난 시간 미상 시 정오 가정·시주 미표시.
- 중국 절기 시각과 한국 표준시 차이 및 진태양시 보정은 미구현. 경계일의 정확한 한국 만세력 결과를 보장하지 않는다.
- 성격·술 취향의 과학적 예측 모델로 쓰지 않는다. 일간 오행과 MBTI에 연결한 자체 캐릭터 문구만 출력한다.

3. 블러디 메리와 시저의 재료 차이는 무엇인가?
4. 피냐 콜라다의 문서상 재료와 제조 방식은 무엇인가?
5. 이 레시피만으로 완성된 한 잔의 정확한 도수를 알 수 있는가? (근거가 없으면 확인 불가)
